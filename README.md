# To-Do List

A beginner-friendly command-line To-Do List application developed using Python.

## Features

* View tasks
* Add new tasks
* Delete tasks
* Save tasks permanently
* Read tasks from a text file
* Input validation
* Menu-driven interface

## Technologies Used

* Python
* Python IDLE
* File Handling

## How to Run

1. Download or clone the project.
2. Open `todo.py` using Python IDLE.
3. Press `F5` or select Run → Run Module.
4. Choose an option from the menu.
5. Add, view, or delete tasks.
